# Using This Guide

Welcome to the CCC Guide — a **free, open-source** resource for the Canadian Computing Competition. From your first Junior contest to the path toward CCO, find curated lessons, practice materials, and strategies designed for self-paced learning.

## Expected Knowledge

The CCC Guide **does not** provide general programming language tutorials. If you are unfamiliar with the language you wish to use, we recommend learning it first through the following resources.

<Cards>

<Card
  title="W3Schools Online Web Tutorials"
  href="https://www.w3schools.com/"
  description="A modern online learning platform offering beginner-friendly tutorials, interactive examples, and references for a wide range of programming languages and web technologies."
/>

<Card
  title="CEMC Courseware"
  href="https://cemc.uwaterloo.ca/resources/courseware"
  description="Official course materials from the Centre for Education in Mathematics and Computing, providing introductory programming resources and computational problem-solving content."
/>

</Cards>

In **Junior**, the programming language knowledge required for each topic will be listed in the prerequisites. However, in **Senior Core** and beyond, this guide assumes that you are **already comfortable** using your chosen programming language.

## Contribute

This guide is open source and improved through community contributions: fixing explanations, adding new content, and suggesting better practice problems. The source for every page is available at [github.com/Moreallure/ccc-guide](https://github.com/Moreallure/ccc-guide) — pull requests are welcome.
