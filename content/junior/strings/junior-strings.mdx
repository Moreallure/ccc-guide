# Strings: parsing, transforms, palindromes

## From Characters to Strings:

Before learning about strings, we need to know how characters are stored

In modern computers (or rather, in our contests), we use the ASCII table to convert between characters and binary. For contests, though, you just need to master a few neat tricks

When we XOR a character with 32, we can convert it from uppercase to lowercase, or from lowercase to uppercase.

This is because `'A'` has a decimal value of 65, while the lowercase `'a'` is 97

Similarly, for a digit character, we can get its corresponding integer value like this:

```cpp
int(c-'0');
```

By the same logic, when we have a string made up exclusively of digit characters, we can also get its corresponding number using the following method:

```cpp
string s;
cin>>s;
int v=0;
for(int i=0;i<s.size();i++){
    v=v*10+int(s[i]-'0');
}
cout<<v;
```

Not only that, we can also shift characters—for example, to implement a Caesar cipher. Just remember to `MOD 26`, otherwise it'll turn into random other characters

```cpp
char a;
int shift;
cin>>a>>shift;
cout<<char((int(a-'a')+shift)%26+'a');
```

## What is a String?

A string is one of the fundamental data structures in modern programming languages (an STL container). It's super important, and under the hood, it's essentially a character array—which literally just means a bunch of characters strung together.

- Something like: `"PY is the best language in the world.cpp"`

In upcoming problems, we'll be dealing with two concepts: substrings and subsequences

- Subsequence: the relative order of each character stays the same, and they don't have to be contiguous
  - For example, `"PY best"` is a subsequence of `"PY is the best language in the world.cpp"`
- Substring: a contiguous slice of characters taken from the original string
  - For example, `"world.cpp"` is a substring of `"PY is the best language in the world.cpp"`

We can use

```cpp
string s;
// Similar to char s[10001];
```

to define a string and access it via indices. Note that string indexing starts at 0

With that, we can perform basic operations on strings—namely: append/insert, delete, modify, search, and traverse.

```cpp
s+="str";// Append to the end, worst-case complexity O(n), fixed length of added content
s.insert(i,"str");// Insert at index i, worst-case complexity O(n), fixed length of inserted content
s.erase(s,l);// Erase l characters starting from index s, complexity O(n)
s[i]='a';// Modify the i-th character, complexity O(1)
for(int i=0;i<s.size();i++){// Traverse the entire string and search
    if(s[i]=='t'){
        cout<<i<<" ";
    }
}
```

Beyond these, there are a few other commonly used methods you need to know, such as:

```cpp
reverse(s.begin(),s.end());// Reverse the entire string, O(n)
s.substr(s,l);// Extract a substring of l characters starting from s, O(l), not exceeding the remaining length
```

Well then, congrats! You've learned the most basic string operations. Next, let's dive into some more advanced algorithms

## Palindromes

A palindrome is a special kind of string that reads the exact same forwards and backwards

- For example: `"ABCBA"` is a palindrome

In some problems, we'll run into scenarios where we need to check if a string is a palindrome

So:

- We can first make a copy of the original string `string co(s);`
- Then reverse it `reverse(co.begin(),co.end());`
- And finally just check if `co` and `s` are equal

Alternatively:

- We can traverse the string from both ends at the same time; if we run into mismatching characters, we mark it as `false`, and `true` otherwise

```cpp
bool mark=1;
for(int i=1;i<=s.size()/2;i++){
    if(s[i-1]!=s[s.size()-i+1-1]){
        mark=0;
        break;
    }
}
```

## Example Problem 1: J3 Secret Instructions

Same old rule: analyze the problem first as soon as we get it

In other words:

- Except for the last line, the first two digits of each line tell us which way to turn, while the last three digits tell us the distance
- When we read in `"99999"`, the program terminates

A super simple problem

- After reading in the data (`s`), grab the first two digits, add them up, and check whether the sum is odd, even, or zero

  ```cpp
  int ch=int(s[0]-'0')+int(s[1]-'0');
  if(ch==0){
      cout<<dir;
  }else if(ch%2==0){
      cout<<"right ";
      dir="right ";
  }else{
      cout<<"left ";

  }
  ```

- Then grab the last three digits:

  ```cpp
  int d=int(s[2]-'0')*100+int(s[3]-'0')*10+int(s[4]-'0');
  cout<<d<<endl;
  ```

And just like that, we can breeze through this cakewalk of a problem:

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
    string s="";
    string dir="";
    while(1){
        cin>>s;
        if(s=="99999"){
            return 0;
        }
        int ch=int(s[0]-'0')+int(s[1]-'0');
        if(ch==0){
            cout<<dir;
        }else if(ch%2==0){
            cout<<"right ";
            dir="right ";
        }else{
            cout<<"left ";
            dir="left ";
        }
        int d=int(s[2]-'0')*100+int(s[3]-'0')*10+int(s[4]-'0');
        cout<<d<<endl;
    }
}
```

## Example Problem 2: J3 Rövarspråket

Let's look at the problem:

<ProblemSections component={Rovarspraket} meta={rovarMeta} />

Following the processing logic, our program should look something like this

1. Read in the data
2. Traverse and process the string

   - If the current character is one of `aeiou`, append it directly to the `ans` string
   - Otherwise

     - First append it to the `ans` string
     - Then handle the vowel closest to this consonant

       - First, create a vowel table

         ```cpp
         string vol="aeiou";
         ```

       - The position of a lowercase letter in the alphabet can be found with the following code (0-indexed)

         ```cpp
         int(s[i]-'a')
         ```

       - When processing this character, we first compare it against all vowels to find the vowel that comes after this character

         - If we don't find one, it means the letter comes after `u`, so we just append `u` directly
         - Otherwise, we need to find its distance to the previous vowel and its distance to the next vowel (in the code below, `vol[j]` refers to the vowel that comes after the current letter)

           ```cpp
           if(s[i]-vol[j-1]==vol[j]-s[i]){
               ans+=vol[j-1];
           }else{
               if(s[i]-vol[j-1]>vol[j]-s[i]){
                   ans+=vol[j];
               }else{
                   ans+=vol[j-1];
               }
           }
           ```

     - Next, handle the following consonant

       - Same old routine: set up a consonant table first

         ```cpp
         string con="bcdfghjklmnpqrstvwxyz";
         ```

       - Then find the current letter's position in the consonant table and just add 1 to the index
       - Watch out for `z` though—it needs a special case check

         ```cpp
         for(int j=0;j<con.size();j++){
             if(s[i]=='z'){
                 ans+="z";
                 break;
             }
             if(s[i]==con[j]){
                 ans+=con[j+1];
                 break;
             }
         }
         ```

3. Finally, output the answer `ans`

And that solves the problem! Solution:

```cpp
#include<bits/stdc++.h>
using namespace std;
string vol="aeiou";
int pov[5]={0,4,8,14,20};
string con="bcdfghjklmnpqrstvwxyz";
int main(){
    string s;
    cin>>s;
    string ans="";
    for(int i=0;i<s.size();i++){
        bool flg=0;
        for(int j=0;j<=4;j++){
            if(s[i]==vol[j]){
                ans+=s[i];
                flg=1;
                break;
            }
        }
        if(flg){
            continue;
        }
        ans+=s[i];
        flg=0;
        for(int j=0;j<=4;j++){
            if(vol[j]>s[i]){
                flg=1;
                if(s[i]-vol[j-1]==vol[j]-s[i]){
                    ans+=vol[j-1];
                }else{
                    if(s[i]-vol[j-1]>vol[j]-s[i]){
                        ans+=vol[j];
                    }else{
                        ans+=vol[j-1];
                    }
                }
                break;
            }
        }
        if(!flg){
            ans+='u';
        }
        for(int j=0;j<con.size();j++){
            if(s[i]=='z'){
                ans+="z";
                break;
            }
            if(s[i]==con[j]){
                ans+=con[j+1];
                break;
            }
        }
    }
    cout<<ans;
}
```

## Example Problem 3: J3 Cold Compress

This one's even easier than the last—even my grandma could AC it

<ProblemSections component={ColdCompress} meta={coldMeta} />

We need to implement RLE (run-length-encoding), so the idea goes like this:

- Traverse the entire string, and while we're at it, set up some initial values; starting directly from the second character makes things much more convenient

  ```cpp
  int cnt=1;
  char c=s[0];
  ```

- `cnt` is the count of occurrences, and `c` is the current character
- While traversing the string:
  - If this character is the same as `c`, do `cnt++`
  - Otherwise, output `cnt` and `c`, and update `cnt` and `c` to the current state
- At the very end, output `cnt` and `c` one more time so we don't miss the last segment

Well then, congrats—you just pocketed another 15 free points on the CCC-J

AC Code:

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
    int nt;
    cin>>nt;
    for(int t=1;t<=nt;t++){
        string s;
        cin>>s;
        int cnt=1;
        char c=s[0];
        for(int i=1;i<s.size();i++){
            if(s[i]!=c){
                cout<<cnt<<" "<<c<<" ";
                cnt=1;
                c=s[i];
            }else{
                cnt++;
            }
        }
        cout<<cnt<<" "<<c<<endl;
    }
}
```
