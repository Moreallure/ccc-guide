# Getting Started

## Pick your track

Most contestants start with the Junior track and move up. The two tracks share the same craft layer (I/O, complexity intuition, debugging), so nothing is wasted.

## Setting up

<Steps>
  <Step>
    Pick one language and stick with it — Python 3 is the recommended default.

    Set it up once, then never think about tooling again mid-season.
  </Step>

  <Step>
    Learn the I/O discipline: read from stdin, write to stdout, no prompts.

    Every CCC problem since 2012 uses exactly this format.
  </Step>

  <Step>
    Practice with past problems from the [CEMC archive](https://cemc.uwaterloo.ca/contests/past_contests.html).

    Start with J1–J3 to build speed, then move up.
  </Step>
</Steps>

<Callout type="info" title="Partial credit">
  Every problem is scored out of 15 by subtask. A partial solution that passes early subtasks is worth real marks — always submit what you have.
</Callout>
